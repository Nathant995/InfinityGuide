Building guide

Make a useful home before making a huge one.

Start with a small, useful space

At the shared camp, ask where you may build. A sensible first project is a compact sheltered space with room to move, an available bed and access to storage and workstations. Test the layout before expanding.

  1. Choose a permitted area that does not block paths or entrances.
  2. Open Build mode and choose the piece you want.
  3. Read its material requirement and inspect the placement preview.
  4. Place it only when the game accepts the position.
  5. Walk around the finished piece. Check that doors, workstations and other players still have enough space.

When a piece will not place

  • Check whether you have the correct materials, not merely a similar-looking item.
  • Look for overlap with terrain, other pieces or an occupied space.
  • Try a simpler ground-level layout and check the current placement rules.
  • Move away from restricted areas. Some game areas intentionally prevent construction.
  • Read the preview warning rather than repeatedly clicking the same invalid location.

Protect the shared village

Ask before removing walls, moving workstations or cutting trees close to someone else’s building. A quick change can make another player’s layout unusable. Keep exits obvious and avoid using your build tools while standing beside a structure you do not own.

For larger projects, sketch the footprint first and agree where gathering, cooking, storage and social spaces will go. Keep the working camp usable while the new part is built.

Build for a shared settlement

  • Use the host’s designated building area. Keep walking routes and workstations accessible.
  • Ask about a Build Protection Totem and Lightning Rod before investing heavily in exposed structures. Read each item’s protection limits in game.
  • Use personal chests for personal supplies and agree on communal storage labels. A Storage Ledger can support organised settlement storage.
  • Repair damaged structures through Build Mode (default B), then the repair action (default T). Check walls and crafting areas after attacks.

For exact building categories and object requirements, consult the Buildings wiki reference below.
