# Infinity Guide upgrade

This release expands the saved wiki reference material into practical searchable tables covering station construction requirements, recipes, material counts, unlock levels and skill progression.

## Using the guide
- On desktop, navigate with the side menu, search shortcut `/`, and article contents.
- On phones, tap ☰ to open the menu. Use each table’s search field and swipe sideways for wide recipes.
- Saved articles, reading progress and checklists remain stored only in the reader’s browser.
- The roadmap panel is an editorial summary of announced future content; confirm release details directly with Jagex.

## Deploy
Copy the files **inside InfinityGuide/** to the GitHub Pages publishing root. Keep `.nojekyll`.

## Image note

## Information sources
The reference data comes from the saved HTML files supplied with the project, and should be checked after major game updates. Some nested wiki tables and interactive elements are excluded to avoid malformed displays.
